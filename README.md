# JSRamverk - Frontend SPA

Detta projekt är en fristående Single Page Application (SPA) byggd med React. Den fungerar som användargränssnitt för dokumentredigeraren i kursen jsramverk och kommunicerar med ett externt API via JSON.

## Installation och uppstart

För att köra projektet lokalt krävs att Node.js är installerat på systemet.

1. **Klona projektet**
   Ladda ner koden till din lokala maskin via git clone.

2. **Installera beroenden**
   Eftersom externa bibliotek inte versionshanteras behöver dessa installeras manuellt:
   ```bash
   npm install
